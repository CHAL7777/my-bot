# Telegram Quiz Bot

A comprehensive quiz bot for remedial students with payment system, progress tracking, and analytics.

## Features
- Chapter-wise quizzes with 3 difficulty levels
- Progress tracking and analytics
- Leaderboards (weekly & overall)
- Screenshot-based payment approval
- Admin panel for question management
- CSV question import
- Subscription system with expiry
